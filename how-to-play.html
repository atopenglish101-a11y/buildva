How to play Buildva

Buildva is a two-player Picking Numbers game you play on your phone. One player creates a game and shares a 6-character code, the other joins with it. That’s all it takes to start.

Create a game

You’re the one starting the game. Pick how many numbers to play with, then send the game code to your opponent.

  1. Choose a number range and tap Create Game

    On the home screen, find Create a Game. Select 1–50, 1–100 or 1–200 to set how many numbers you play with, then tap Create Game.

  2. Type your name and tap Assign Me

    Enter your name in the box, then tap Assign Me. Buildva automatically puts you in the first available player slot.

  3. Share the game code and wait

    When you see You are Player 1, your game is ready. Tap Copy Code or Share to send the 6-character game code to your opponent, then wait here until they join.

Join a game

A friend has already created a game and sent you a code. Here’s how to get in.

  1. Open Buildva and tap Join a Game

    Launch Buildva on your phone and find the Join a Game section on the home screen.

  2. Enter the game code

    Type the 6-character game code your friend shared with you, then tap Join Game.

  3. Type your name and tap Assign Me

    Enter your name and tap Assign Me. When you see Waiting for the host…, you’ve joined. Your friend just needs to start the game.

No code yet? Ask your friend to create a game and tap Copy Code or Share on their screen. The code is 6 characters long.

Quick summary

Not sure which side you’re on? Follow the list that matches you.

If you create the game

  1. Choose 1–50, 1–100 or 1–200.
  2. Tap Create Game.
  3. Type your name and tap Assign Me.
  4. Copy or share the game code.
  5. Wait for your opponent to join.

If you join a game

  1. Open Buildva and go to Join a Game.
  2. Type the 6-character code.
  3. Tap Join Game.
  4. Type your name and tap Assign Me.
  5. Wait for the host to start.
